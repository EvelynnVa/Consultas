# Consultas EGT

## Pagina web para la consulta de informacion y agendacion de citas

La pagina permite la visualizacion de la informacion basica del psicologo y el tipo de consultas que ofrecen, permitiendo verificar si se trata lo que el paciente requiere en el momento, ademas de ello, permite el envio de un correo electronico de forma automatica para que el psicologo lo pueda visualizar en el momento que este libre.

El proyecto sirve para poder ayudar tanto al paciente como al psicologo de las siguientes formas:

### Paciente
* Permite la visualizacion de los tipos de casos que se tratan
* Provee la informacion basica e imagen del psicologo para poder ver con quien se estara tratando
* Posibilita la agendacion de una cita sin necesidad de movimiento fisico, ni contacto directo con una persona, util para posibles casos con ansiedad

### Psicologo
* Abre los clientes posibles al aire, permitiendo mejor visibilidad de sus servicios
* Elimina la necesidad de tener que estar al pendiente del celular todo el dia, pues el envio de correos no requiere de su atencion

Los usuarios pueden ingresar a la pagina (una vez sea publicada) para poder ver la informacion del psicologo y agendar su cita (sujeta a aprobacion por parte del psicologo) al enviar un formulario con sus datos y la fecha deseada.

En caso de ser desarrollador y querer usar el codigo como base para otra pagina o aprendizaje, solamente hay que descargar el proyecto y comenzar con su modificacion, cuenta con los siguientes archivos:

* ### index.html
La pagina base, con su informacion, imagenes y referencias al stylesheet y script, escrita en HTML

* ### stylesheet.css
Es el archivo que le da su estilizacion a la pagina, escrita en CSS

* ### scipt.js
Es el archivo de los scripts para el envio de correos electronicos, ocultacion y revelacion del calendario y las animaciones de los casos disponibles a tratar por el psicologo

* ### config.js
Es un archivo para mantener varios datos confidenciales durante el desarrollo, aqui se tienen los datos para que sean referenciados en el index.html y scipt.js
